🎓 STUDORA

Your AI-Powered Student Life Companion

STUDORA is an all-in-one student productivity and learning companion designed to make academic life smarter, easier, and more organized.

It combines academic management, personal productivity, financial tracking, and everyday student utilities with optional AI-powered learning features. AI requires Firebase configuration by the maintainer and is not enabled in the current public build; AI actions show a clear coming-soon message until configured.

🎯 Project Purpose

The main goal of STUDORA is to create a centralized digital space where students can manage their studies, organize learning materials, plan daily activities, track expenses, and improve productivity without depending on multiple separate applications.

💾 Local Storage & Offline Support

STUDORA follows a Local-First Architecture.
- SQLite-based local database (Android Room).
- Persistent storage for PDFs, images, and audio.
- Offline access to saved information.
- No mandatory login or registration.
- No mandatory cloud database.
- Local backup and restore support.

Internet is required for new AI generation and live website access, while previously saved content remains available offline.
